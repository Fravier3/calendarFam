# Centro Vazquez Santiago

PWA móvil y visor Android TV. Ejecuta `npm ci` y `npm run build`. El visor abre el despliegue en modo horizontal. Usa la misma cuenta en el teléfono y la TV. Appwrite guarda los registros y las fotos con permisos por cuenta.

Compila la APK con `android/build.sh`, las herramientas Android SDK, los fondos WebP y un almacén de firma externo. Las claves y las fotos familiares quedan fuera del repositorio.
